# Public consultation response analysis

The department ran a consultation and received 41,000 responses. They are due to
publish an analysis in eight weeks and have four analysts.

This is one job, not a pipeline: read the responses, classify each against the
consultation's question set and the emerging themes, extract the specific
policy proposals people made, reconcile the quantitative answers against the
free-text ones where they disagree, and produce the published analysis report
with the thematic breakdown.

It runs once. If the analysis is good they will want the same thing for the next
consultation, but that is not this piece of work.

The full response corpus is about 90 MB of text, so how it is chunked and
retrieved is the whole engineering problem here.
