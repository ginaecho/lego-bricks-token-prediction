Inside the estimate: bricks, rates, and limitations

Inspired by this repository's decompose-and-recompose approach. These hand-authored demo coefficients are not fitted weights, benchmark results, or current provider prices.

  • Feature tokens = runs per feature x sum of its atomic input and output tokens. Reasoning and cache are not modeled.
  • Connection count = n x (n - 1) / 2. Every selected pair is assumed to need an integration.
  • Each connection adds 120 input + 30 output tokens per monthly run, multiplied by integration complexity.
  • One-time integration uses Plan + Transform + Validate: 18,000 input + 6,000 output tokens per connection, multiplied by complexity. This is hypothetical AI-assisted integration work, not labor.
  • Cost = (input tokens x input rate + output tokens x output rate) / 1,000,000. Reserve applies to cost only, not tokens.
  • No assumed batching savings, guaranteed engagement uplift, or carbon conversion. Lower tokens alone do not establish sustainability.
