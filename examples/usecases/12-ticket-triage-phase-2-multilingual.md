# Contoso ticket triage — phase 2, European desks

Extension of the Contoso triage pipeline into the German, French, Spanish and
Polish desks. The routing taxonomy and the priority bands are the same; the
order history retrieval is the same system.

What is genuinely new: the response drafts have to be in the customer's
language and match the tone each country desk already uses, and two of the
markets have statutory response wording for returns that has to be checked
rather than drafted freely.

So per ticket: classify, retrieve history, draft the localised response, and
validate the statutory wording where the market requires it.

Adds about 14,000 tickets a week on top of the UK volume. Same client, same
platform, same delivery team.

Team: same as phase one, plus a change manager for the four country desks.
Each has its own way of working and the UK rollout did not have to deal with
that.
