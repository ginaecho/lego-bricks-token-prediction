The big idea

The marketplace is the front door.
The evidence loop improves what is behind it.

Users choose capabilities, not tokens. The system translates those choices into measurable work. New kinds of work enter a discovery-and-validation cycle before they can become supported, reusable bricks.

A concrete example / AI customer support

Marketplace capability → Retrieve + Draft + Validate → planned counts and context → a token forecast. Capability-to-brick mapping comes from the marketplace prototype; its coefficients are illustrative.

Evidence boundary / What exists today

The measured pilot uses Extract, Classify, Plan, and Report with small ridge-regression predictors for scoping work, not full product delivery. Broader marketplace coverage and this automated learning loop are proposed. Re-distillation means discovering task units, not fine-tuning the execution LLM.
